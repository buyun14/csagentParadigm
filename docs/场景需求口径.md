# 场景需求口径（唯一真相）

> 代码政策源：[`src/lib/agent/policy.ts`](../src/lib/agent/policy.ts)  
> 本文与代码枚举同步；若冲突以 `policy.ts` 为准。

## 1. 唯一使命

**外呼线索初筛**：在不报精准落地价的前提下，尽快收齐五项并口头授权交 4S。

- 不是导购 / 不是报价员 / 不是闲聊陪聊
- 成功结束：五项齐备 → `FAREWELL`
- 失败结束：辱骂 / 强反感 / 同一缺失项连续 3 轮未推进（stall）→ 礼貌挂机

## 2. 采集契约（仅五项）

| 槽位 | 语义 | 合法来源 |
|---|---|---|
| brand | 意向品牌 | 知识库品牌表 |
| series | 意向车系 | 该品牌下车系列表 |
| city | **购车城市** | 明确地名 |
| timing | **购车时间意向** | 受控枚举 |
| surname | 姓氏（口头授权） | 姓氏表 / `姓X` |

**不收集**：手机号/尾号、动力类型、车身类型、配置、颜色、精准价。  
`phoneTail` / `vehicleType` / `powerType` 仅为被动兼容字段，**不得驱动提问与闭环**。

### timing 受控枚举

`近期` | `半个月后` | `本月` | `下个月` | `今年` | `明年` | `不着急` | `已看车` | `看价格`

## 3. 有限异议分支

每类异议：**1 句承接 + 立刻回到「下一缺失项」**。

| 分支 | 触发 | 允许 | 禁止 |
|---|---|---|---|
| PRICE | 多少钱/优惠 | 说明 4S 核算；可将 timing=`看价格` | 报价、与时间死锁 |
| CONFIG | 配置/续航 | 软拒 + 问缺失项 | 展开参数 |
| CHANNEL | 加微信/哪家店 | 授权 4S 跟进 | 加好友流程 |
| BUSY | 等一下 | wait 话术，不推进 | 换话题 |
| REJECT | 不需要 | 挽留 **仅一次**，再拒退出 | 多轮推销 |
| ABUSE/DISLIKE | 辱骂/别打了 | 立即 FAREWELL | 争辩 |
| OFF_TOPIC | 闲聊/推荐/动力筛选 | 一句拉回 | 顺着聊 |

`ask_recommend` / `filter_vehicle` **不是主路径**，命中后按 OFF_TOPIC 拉回采集。

## 4. 回合纪律

1. 每轮只问 `nextMissing(slots)` 对应的一项  
2. 已入槽字段绝不回问（含开场句）  
3. 状态由槽位推导下限：`stateFromSlots` / `advanceState`（只进不退；`FAREWELL` 终态）  
4. 车系列表：仅在缺车系且已有品牌时允许列；客户已报名车系后禁止再列全表  

## 5. 实体入槽门禁

```
精确匹配 → 直接入槽
软匹配（近音）→ pending 复述确认（「是宋PLUS对吧？」）→ 客户肯定再入槽
歧义 / 跨品牌 → 不入槽，追问本轮缺失项
```

- 品牌未确认：禁止短词全局软匹配  
- 品牌已确认：软匹配仅在该品牌车系内  
- ASR 词表只保留结构型（字母数字）；中文近音走软匹配 + Prompt 纪律  

## 6. 验收（规则模式可复现）

1. 捷途 +「旅行者」精确 → 入槽问购车城市，不列全表  
2. 「送plus」软匹配 → 只复述确认，肯定后才入槽  
3. 「我看蔚来」→ 只入品牌，不误入车系  
4. 问价 → 不报价格、不与时间死锁  
5. 五项齐后禁止再要手机号 → 强制 FAREWELL  
6. 连续 3 轮答非所问 → stall 退出
