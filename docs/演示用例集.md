# 演示用例集

> 全部用例基于 `rule` 模式（纯本地，可离线复现），预期行为已通过 `scripts/demo-walkthrough.ts` 实测验证。
> dual/llm 模式为同一状态机 + LLM 双通道编排，主流程行为一致（快通道失败自动降级回本表结果）。
> 运行验证：`pnpm exec tsx scripts/demo-walkthrough.ts`

## 1. 正常闭环（连续对话，核心主流程）

| # | 客户输入 | 预期状态迁移 | 预期回复要点 |
|---|---|---|---|
| 1 | 你好 | 缓存命中 GREETING:greet | 开场白（报价/了解） |
| 2 | 我看蔚来 | GREETING→MODEL_INQUIRY | 列出蔚来车系（ET5/ET7/ES6/…） |
| 3 | ES8 | MODEL→CITY_INQUIRY | "ES8可以的，想了解哪个城市的价格呢？" |
| 4 | 我在北京 | CITY→TIMING_INQUIRY | "北京是吧？考虑什么时候购车呀？" |
| 5 | 下个月 | TIMING→CONTACT_COLLECTION | 授权 4S 报价 + 问贵姓 |
| 6 | 我姓王 | CONTACT→FAREWELL | "王先生，稍后报价，早日提爱车，再见" |

**验收点**：6 个采集字段（品牌/车系/城市/时间/姓氏）全部收集，无重复追问。

## 2. 独立场景

| 场景 | 初始状态 | 输入 | 预期 |
|---|---|---|---|
| 开场问候 | GREETING | 喂你好 | 缓存命中，开场白 |
| 辱骂护栏 | BRAND_INQUIRY | 你傻逼吧 | 缓存命中 ANY:abuse，退出话术 + FAREWELL |
| 反感护栏 | MODEL_INQUIRY | 不要再打了 | intent=dislike，FAREWELL + "理解您的感受…" |
| 偏离拉回 | BRAND_INQUIRY | 今天天气不错哈哈 | intent=off_track，OFF_TRACK + 拉回营销话题 |
| 超范围（价格） | MODEL_INQUIRY（品牌已确认） | 落地多少钱？ | intent=out_of_scope，OUT_OF_SCOPE + 引导 4S 店 |
| ASR 谐音纠错 | GREETING | 未来一十八怎么样 | 识别为 蔚来 ES8（confirm_model） |
| 否定防误收集 | BRAND_INQUIRY | 我不想看蔚来 | intent=disagree，挽留话术，**品牌不入槽** |
| 不回问（品牌已确认） | BRAND_INQUIRY（品牌=蔚来） | 可以 | 推进到 MODEL_INQUIRY，不问品牌 |
| 不回问（车系已确认） | MODEL_INQUIRY（车系=ES8） | 可以 | 推进到 CITY_INQUIRY，不问车系 |
| 姓氏闭环 | CONTACT_COLLECTION | 我姓王 | FAREWELL + 告别话术 |

## 3. 缓存命中（responseSource=cache，跳过 LLM）

| 触发 | 命中键 | 话术 |
|---|---|---|
| GREETING 状态 + 简单问候 | GREETING:greet | 开场白 |
| FAREWELL 状态任意输入 | FAREWELL:farewell | 结束语 |
| 辱骂关键词 | ANY:abuse | "不好意思打扰了，祝您生活愉快，再见" |
| 反感关键词 | ANY:dislike | "理解您的感受…" |
| 等待/忙 | ANY:wait | "好的，您先忙，不着急" |

## 4. 降级路径（responseSource=fallback）

- **触发**：快通道失败 / 超时 / 非 SSE 响应 / JSON 解析失败；
- **行为**：自动降级到规则引擎（本表第 1、2 节结果），流程不中断，调试面板标注"已降级"；
- **慢通道失败**：仅标记 slowStatus=error，不影响主流程回复。

## 5. 特殊令牌（语音信号，文本模拟）

| 信号 | 行为 |
|---|---|
| AI_UNKNOWN ×1~2 | "抱歉，暂时没听清您的问题…"（按知识库轮次） |
| AI_UNKNOWN ×3 | 升级 AI_UNKNOWN_END："…无法回答…找专业顾问" + 挂机 |
| USER_NOT_ANSWER ×1~2 | "喂。在吗" → "喂，您能听到我说话吗？" |
| USER_NOT_ANSWER ×3 | "听不见您的声音，先挂了" + 挂机 |

> 信号由平台侧（ASR/静音检测）注入，计数与动作逻辑已实现（`legacy/special-tokens.ts`）。

## 6. 验收指标（演示时可展示）

- **上下文记忆**：连续 6 轮后问"我刚才说的品牌是什么"→ 能正确复述（槽位 + 摘要）；
- **不回问**：整个闭环 0 次重复追问；
- **首字延迟**：调试面板 first_token 指标可观测；
- **缓存命中**：调试面板显示 responseSource=cache，延迟≈0ms；
- **降级**：断开 LLM 后对话仍可继续（rule 模式）。
